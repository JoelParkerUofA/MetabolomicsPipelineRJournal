\hypertarget{introduction}{%
\section{Introduction}\label{introduction}}

Targeted metabolomics assays quantify a set of predefined small molecules known as metabolites (Roberts et al. 2012). These assays categorize metabolites into sub-pathways based on biological function and further organize sub-pathways into super-pathways. Companies like Metabolon Inc.~utilize proprietary pipelines for preprocessing, exploratory data analysis, and statistical analysis. These pipelines provide customers with raw data, processed data, and analysis results.

While proprietary data analysis workflows can provide researchers with valuable results, they often do not adhere to the F.A.I.R guiding principles for reproducible research, which extends to workflows and pipelines (Goble et al. 2020). Specifically, proprietary pipelines are not reusable and do not allow researchers to replicate the results. Moreover, proprietary workflows are limited to the types of analysis they can perform, with little flexibility to make data-driven analysis decisions. In contrast, utilizing open source software like R to build analysis workflows and distribute them through centralized repositories like the Comprehensive R Archive Network (CRAN) or Bioconductor enables the reuse of workflows for secondary analysis and promotes reproducible research.

For R, several packages are available to analyze targeted metabolomics data. Packages like \pkg{autonomics} (Bhagwat et al. 2024) and \pkg{MetaboloAnalysistR} (Pang et al. 2020) provide open-source tools for preprocessing, batch correction, and analysis of targeted metabolomic data. However, these tools only offer functionality for hypothesis testing at the metabolite level and do not support hypothesis testing at the sub-pathway level. When hypothesis testing at the sub-pathway level is of interest, we can independently test each metabolite and then combine the p-values within each sub-pathway using the combined Fisher probability test (Westberg 1985). Despite this being an efficient method for hypothesis testing at the sub-pathway level, to the best of our knowledge, there is no R package that implements this method for sub-pathway testing.

In this article, we introduce and demonstrate the \pkg{MetabolomicsPipeline} R package. This package provides analysis tools for targeted metabolomics data, categorized into three categories (figure 1):

\begin{itemize}
\item
  Exploratory analysis
\item
  Sub pathway analysis
\item
  Metabolite pairwise comparisons
\end{itemize}

\begin{figure}
\includegraphics[width=1\linewidth,height=1\textheight]{figures/Workflow} \caption{MetabolomicsPipeline workflow}\label{fig:Workflow}
\end{figure}

The \pkg{MetabolomicsPipeline} package utilizes the \pkg{SummarizedExperiment} (M et al. 2024) package to organize targeted metabolomics data into a standard data structure, facilitating easy integration into preexisting genomic workflows. Analysts can create interactive heatmaps to sort through and interpret analysis results quickly. In addition to the R package, an R shiny app is available with all of the functionality of the R package, providing an intuitive and interactive interface for users.

The remainder of this paper is organized as follows. Section 2 discusses the package design and structure, providing detailed information on the analysis methods and algorithms used. Section 3 illustrates the application of the package through a case study using targeted metabolomic data from Metabolon.

\hypertarget{package-design}{%
\section{Package Design}\label{package-design}}

Metabolon Inc.~provides customers with raw, batch-corrected, and standardized data generated from their proprietary pipeline. Additionally, they include chemical annotation data, detailing the sub-pathway and super-pathway for each metabolite, as well as sample metadata for each sample in the experiment. Metabolon consolidates all this information into a single Excel file. By organizing the experimental data into a SummarizedExperiment class, users can maintain all relevant information throughout the entire workflow. While the \pkg{MetabolomicsPipline} package includes wrappers for quickly loading Metabolon Inc.~experiments into a SummarizedExperiment using the `load\_metabolon' function, the rest of the \pkg{MetabolomicPipeline} package is versatile enough to analyze experimental data from any targeted metabolomics assay that can be organized into a SummarizedExperiment data class. \hypertarget{exploratory-analysis}{%
\subsection{Exploratory analysis}\label{exploratory-analysis}}

The \pkg{MetabolomicsPipeline} package provides visualization tools that overlap with a few preexisting pipeline lines. In the exploratory analysis, we include PCA and heatmap visualizations, which allow us to graphically display sources of variation within the assay data.

Trying to visualize technical or biological sources of variation in the metabolomic profiles is challenging due to the high dimensional nature of the data. PCA is a valuable tool for reducing the dimensionality of the data by transforming the high dimensional data into new uncorrelated variables (principal components) that explain a maximal amount of the variance in the original data. Plotting the first two principal components together in a scatter plot reveals meaningful groupings and sources of variation. PCA also serves as a valuable quality control tool by highlighting technical sources of variation and may influence upstream and downstream analysis decisions. For example, if samples from different batches group together, the data must be batch-corrected before continuing with the downstream analysis. Using the \texttt{metabolite\_pca} function, users can simultaneously calculate and plot the principal components while highlighting factors contributing to the variation in the metabolomic data.

Heatmaps are versatile tools for visualizing metabolite trends and spotting correlations within the data. The \texttt{metabolite\_heatmap} function in the MetabolomicsPipline package displays the top metabolites based on the average metabolite levels. This function organizes data within a SummarizedExperiment to leverage the functionality of the \CRANpkg{pheatmap} (Kolde 2019) package to create well-annotated heatmaps. Annotated heatmaps allow researchers to easily spot trends and/or abnormalities across the experimental conditions.

\hypertarget{sub-pathway-analysis}{%
\subsection{Sub-pathway analysis}\label{sub-pathway-analysis}}

Targeted metabolomic assays quantify predefined metabolites. Therefore, the assay data contain the amount of each chemical compound in each sample, where each sample is a replicate of the experimental conditions of interest. The metabolites are classified into predefined groups, called sub-pathways, based on their biological functions. These sub-pathways are further grouped within broader categories known as super-pathways. After preprocessing and standardization, researchers commonly use univariate analysis of variance (ANOVA) to test if a significant amount of variance in the metabolite levels is explained by the experimental groups . While this is effective for independently testing each metabolite, it does not allow us to test the hypotheses at the sub-pathway level where each sub-pathway contains one or more metabolites.

To test metabolic profiles at the sub-pathway level, we can combine the results for each independently tested metabolite within the sub-pathway using the combined Fisher probability method (Westberg 1985). To explain the details of this method, we will first explain the modeling procedure at the metabolite level and then explain how the results are combined. The following modeling strategy outlines the \texttt{subpathway\_analysis} function in the \pkg{MetabolomicsPipline} package.

For each metabolite, we consider experimental designs that can utilize two-way ANOVA, such as randomized block designs. We employ a nested ANOVA modeling strategy to consider three different models.

1.) Interaction: \(metabolite = Treatment Group + block + Treatment*block\)

2.) Parallel: \(metabolite = Treatment Group + block\)

3.) Single: \(metbabolite= Treatment\)

In the interaction model, we test for a significant interaction between the treatment and block variables, focusing on the p-value for the interaction term. In contrast, the parallel model examines the treatment and block variables without the interaction term, assessing whether the blocking variable explains a significant amount of variation in the metabolite levels; thus, we only consider the p-value pertaining to the block variable. Lastly, the final model includes only the treatment group to determine if there are significant differences in average metabolite levels by treatment group.

Once we have the p-values for each model, we can test the hypothesis from each model at the sub-pathway level using the combined Fisher probability method. In this method, the p-values for each independently tested metabolite within the sub-pathway are transformed and summed to create the chi-squared test statistic \(X\) using the following function:
\[
X = -2\sum_{i=1}^k ln(p_i)
\]
where \(k\) is the number of metabolites within the sub-pathway. The resulting test statistic \(X\) follows a chi-squared distribution with \(2k\) degrees of freedom. This allows us to combine the p-values from multiple independent tests into a single test at the sub-pathway level.

The MetabolomicsPipeline package also provides ways to summarize the sub-pathway analysis results, including:

\begin{itemize}
\item
  Significant sub-pathways by model (subpath\_by\_model)
\item
  Proportion of significant sub-pathways within super pathways (subpath\_within\_superpath)
\item
  Metabolite results within sub-pathways (met\_within\_sub)
\end{itemize}

Additionally, the package provides functionality to help visualize the data within sub-pathways identified in the sub-pathway analysis. Using the \texttt{subpathway\_lineplot} and \texttt{subpathway\_boxplot} functions, users can efficiently create line plots and box plots for each metabolite within a sub-pathway. These functions leverage the ggplot2 package, allowing users to tailor the plots to their needs.

\hypertarget{pairwise-comparisons}{%
\subsection{Pairwise comparisons}\label{pairwise-comparisons}}

We can compare group means between the experimental groups to identify metabolites that differ between them. When the metabolite levels are on the log scale, this translates to differences in log fold changes between groups. The \pkg{MetabolitePipeline} package provides functionality to test all pairwise group comparisons for each metabolite using the \texttt{metabolite\_pairwise} function. The challenge with comparing pairwise group means, is preserving the family-wise error rate (FWER). If each comparison is performed with a significance level of \(\alpha=0.05\), then the FWER (the probability of incorrectly rejecting at least one test) increases.

A first step to preserving the FWER at a prespecified level is to first filter metabolites using ANOVA to test if any of the experimental group means were significantly different. Metabolites showing an overall difference in group means are then subjected to pairwise comparisons. The \texttt{metabolite\_pairwise} function provides the p-value for the overall test of significance as well as the unadjusted p-values for each of the pairwise comparisons. This allows the analyst the freedom to use any post-hoc p-value adjustment for their specific need.

The \pkg{MetabolomicsPipline} package provides tools for summarizing the results from pairwise comparisons using heatmaps. Specifically, the `metabolite\_est\_heatmap' and the `metabolite\_pvalue\_heatmap' functions create heatmaps that organize metabolites in the rows and pairwise comparisons in the columns, providing a visual summary of mean difference estimates and p-values. Below, we highlight a few details about the heatmaps.

\begin{itemize}
\item
  Inclusion Criteria: Metabolites that do not reject the overall test of significance at the \(\alpha = 0.05\) level are excluded from both heatmaps.
\item
  Organizational Structure: Metabolites grouped by sub-pathway.
\item
  Mean difference heatmap (metabolite\_est\_heatmap): This heatmap highlights group comparisons with a mean difference greater than 2. When the metabolite data is on the log scale, this corresponds to a log fold change greater than 2.
\item
  P-value heatmap (metabolite\_pvalue\_heatmap): This heatmap highlights group comparisons with a statistically significant mean difference.
\end{itemize}

Each heatmap has a static or interactive option. The interactive heatmap option is valuable because it allows users to zoom in on particular areas of the heatmap and quickly identify sub-pathways with several significant metabolites for a given comparison. Hovering over the heatmap provides useful information about the given metabolite, including metabolite name, sub-pathway, super-pathway, and pairwise comparison results.

\section{Summary}\label{summary}}

Targeted metabolomics is a valuable tool for identifying biomarkers. Companies like Metabolon Inc.~utilize proprietary software to analyze the data and deliver results to the customer. However, these types of software often do not follow reproducibility best practices, which can limit the transparency and repeatability of the research. In contrast, using open-source tools like R, facilitates reproducibility by allowing researchers to share and collaborate on open-source pipelines.

We demonstrated a new package, \pkg{MetabolomicsPipeline}, for analyzing targeted metabolomics data. The package contains tools for exploratory analysis, sub-pathway analysis, and pairwise comparisons across experimental groups. It supports data that can be organized into a SummarizedExperiment data class. This package also provides functionality to visually display the results from each analysis step, including various graphs and tables. When analyzing pairwise comparisons, users can create interactive heatmaps, enhancing the presentation of results. We provide all the functionality of the MetabolomicsPipeline through a user-friendly interface built with R Shiny, ensuring ease of use for researchers.
